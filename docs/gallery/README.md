# MotionForge gallery previews

Folder ini berisi preview gambar gallery dari [Bang Motion](https://github.com/bangtutorial/bang-motion/tree/main/docs/gallery) oleh Bang Tutorial.

Gambar disimpan untuk dokumentasi dan preview README; tidak diubah dari sumbernya. Gunakan gallery sebagai referensi arah visual, bukan untuk menyalin teks, layout, palette, font, scene order, karakter, atau signature moment.

Lihat [README utama](../../README.md) untuk katalog lengkap dan [gallery reference skill](../../skills/motionforge/references/gallery.md) untuk instruksi agent.
