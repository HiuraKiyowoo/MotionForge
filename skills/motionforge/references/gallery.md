# MotionForge gallery — style selector

Use this reference when the user asks for a visual style, provides no style, or wants to browse examples. The canonical visual gallery is maintained upstream at [Bang Motion gallery](https://github.com/bangtutorial/bang-motion/tree/main/docs/gallery). The images are references for **look, rhythm, and production direction**—not scripts, layouts, copy, or scenes to clone.

## How to use the gallery

1. Ask for or infer the product/topic, audience, ratio, duration, audio/VO, and brand assets.
2. Choose **one** gallery direction as a starting point, or present three candidates when the user has not chosen a look.
3. Write a style brief: palette and source, display font, surface, background motion, render family, camera language, transition family, and one special moment.
4. Select the matching starter/reference from the table.
5. Invent a new concept, copy, scene order, and asset composition from the user's topic. Keep the gallery's principles, not its exact skin.
6. Run the anti-PPT checks before delivery.

## What may and may not carry over

Carry over the visual principle: grainy gradient, poster color blocks, click-driven UI, flowing subject, collage paper, catalog grid, or evidence-led annotation. Do **not** carry over exact text, palette, font pairing, composition, scene order, characters, image crop, logo treatment, or signature moment from a gallery image. If the user says “buat persis seperti contoh”, explain that MotionForge can match the energy and production language while creating an original treatment.
